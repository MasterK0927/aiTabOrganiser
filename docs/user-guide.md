# User Guide

Welcome to AI Tab Organiser! This comprehensive guide will help you master all the features and get the most out of your tab management experience.

## 🎯 Overview

AI Tab Organiser automatically groups your browser tabs into meaningful workspaces using machine learning. Instead of manually organizing dozens of tabs, let AI do the heavy lifting while you focus on what matters.

## 🚀 Getting Started

### First Time Setup

1. **Install the Extension** (see [Installation Guide](installation.md))
2. **Click the Extension Icon** in your browser toolbar
3. **Complete the Onboarding Tutorial** - introduces key features
4. **Grant Permissions** when prompted (tabs and storage access)

### Quick Start

1. **Open Multiple Tabs** (5+ recommended for best results)
2. **Click "Analyze Tabs"** in the extension popup
3. **Wait for Processing** (usually 2-5 seconds)
4. **Review Generated Workspaces** - tabs grouped by similarity
5. **Click a Workspace** to open all its tabs

## 🔧 Core Features

### Tab Analysis & Grouping

The heart of AI Tab Organiser is its intelligent tab analysis system.

#### How It Works
- **Content Analysis**: Examines page titles, URLs, and content
- **Similarity Detection**: Uses ML algorithms to find related tabs
- **Smart Grouping**: Creates logical workspaces based on context
- **Automatic Naming**: Generates descriptive workspace names

#### Starting Analysis
1. **Click the Extension Icon**
2. **Press "Analyze Tabs"** button
3. **Select Tab Source** (current window, all windows, or specific window)
4. **Wait for Results** - processing indicator shows progress

#### Best Practices
- **Open 5+ tabs** for meaningful groupings
- **Mix different types** of content (work, research, entertainment)
- **Keep tabs loaded** (not just bookmarks) for better analysis
- **Use descriptive page titles** when possible

### Workspace Management

Workspaces are collections of related tabs that you can manage as groups.

#### Viewing Workspaces
- **Workspace List**: Shows all created workspaces
- **Tab Count**: Number of tabs in each workspace
- **Preview Icons**: Visual indicators of workspace content
- **Search Bar**: Find specific workspaces quickly

#### Workspace Actions

##### Opening Workspaces
```
Click any workspace → Opens all tabs in new window
Ctrl/Cmd + Click → Opens tabs in current window
```

##### Renaming Workspaces
1. **Hover over workspace name**
2. **Click the edit icon** (pencil)
3. **Type new name**
4. **Press Enter** to save

##### Deleting Workspaces
1. **Click the delete icon** (trash can)
2. **Confirm deletion** in the popup
3. **Note**: This only removes the workspace, not the actual tabs

##### Previewing Tabs
1. **Click the preview icon** (eye symbol)
2. **View tab screenshots** and titles
3. **Click any tab** to open it directly

### Search and Filter

Quickly find workspaces and tabs with the built-in search system.

#### Search Workspaces
1. **Use the search bar** at the top of the popup
2. **Type workspace name** or related keywords
3. **See filtered results** in real-time

#### Advanced Search
- **Search by content type**: "pdf", "github", "docs"
- **Search by domain**: "youtube", "stackoverflow"
- **Search by project**: "react", "python", "design"

### Tab Preview System

Get quick previews of tab content without opening them.

#### Accessing Previews
1. **Click the preview button** on any workspace
2. **View tab thumbnails** and metadata
3. **Click thumbnail** to open specific tab

#### Preview Features
- **Visual Thumbnails**: Screenshots of tab content
- **Title and URL**: Easy identification
- **Direct Access**: One-click to open specific tabs
- **Keyboard Navigation**: Arrow keys to browse

## ⚙️ Settings and Configuration

### Accessing Settings
1. **Click the extension icon**
2. **Click "Settings"** in the popup
3. **Or use the gear icon** in the interface

### Tab Source Configuration

Choose which tabs to analyze:

#### Current Window Only
- **Best for**: Focused work sessions
- **Analyzes**: Only tabs in the active window
- **Use when**: Working on specific projects

#### All Windows
- **Best for**: Comprehensive organization
- **Analyzes**: Tabs across all browser windows
- **Use when**: Managing diverse browsing sessions

#### Specific Window
- **Best for**: Selective organization
- **Analyzes**: Tabs from a chosen window
- **Use when**: Organizing specific workspace windows

### Theme Settings

#### Light Mode
- **Clean interface** with light colors
- **Better for**: Daytime use, bright environments
- **Default setting** for most users

#### Dark Mode
- **Dark interface** easier on eyes
- **Better for**: Night time use, dark environments
- **Automatic detection** based on system preferences

### Advanced Settings

#### Grouping Sensitivity
- **High**: Creates more, smaller groups
- **Medium**: Balanced grouping (default)
- **Low**: Creates fewer, larger groups

#### Workspace Naming
- **Automatic**: AI generates descriptive names
- **Manual**: You name all workspaces
- **Hybrid**: AI suggests, you can edit

## 🔧 Advanced Features

### Tab Sandboxing

Isolate tabs in secure environments for testing and privacy.

#### Creating Sandboxes
1. **Click "Create Sandbox"** in the popup
2. **Choose tabs** to include
3. **Select isolation level**
4. **Launch sandbox session**

#### Sandbox Benefits
- **Isolated Storage**: Cookies and data separated
- **Safe Testing**: Test websites without affecting main session
- **Privacy Protection**: Enhanced privacy for sensitive browsing

### Tab Stacking

Organize related tabs in vertical stacks for better visual management.

#### Creating Stacks
1. **Select multiple related tabs**
2. **Right-click** and choose "Stack Tabs"
3. **Or use the stack button** in workspace view

#### Stack Management
- **Expand/Collapse**: Click stack header
- **Reorder**: Drag and drop within stack
- **Unstack**: Right-click and select "Unstack"

### Keyboard Shortcuts

Speed up your workflow with keyboard shortcuts:

```
Ctrl/Cmd + Shift + A    - Analyze tabs
Ctrl/Cmd + Shift + O    - Open workspace manager
Ctrl/Cmd + Shift + S    - Open settings

```

## 💡 Tips and Tricks

### Optimizing Tab Analysis

#### For Better Grouping
1. **Keep tabs active** - loaded pages provide more context
2. **Use descriptive titles** - edit page titles if needed
3. **Mix content types** - combine work and research tabs
4. **Regular cleanup** - remove irrelevant tabs before analysis

#### When Analysis Fails
- **Too few tabs**: Need at least 3-4 tabs for grouping
- **Similar content**: All tabs too similar to create groups
- **Technical issues**: Check browser permissions and try again

### Workflow Integration

#### Project-Based Organization
1. **Open project-related tabs** in one session
2. **Analyze and create workspace** for the project
3. **Use consistent naming** for easy identification
4. **Archive completed projects** by deleting workspaces

#### Research Workflows
1. **Gather research materials** in multiple tabs
2. **Analyze to group** by topic or source
3. **Use preview feature** to review content
4. **Export important links** before closing

### Performance Optimization

#### For Large Tab Sets
- **Process in batches** - analyze 10-20 tabs at a time
- **Close unnecessary tabs** before analysis
- **Use specific window mode** for focused analysis

#### Memory Management
- **Regular cleanup** of old workspaces
- **Close unused tabs** after organizing
- **Monitor browser memory** usage

## 🔍 Understanding AI Grouping

### How the Algorithm Works

The AI analyzes multiple factors:

1. **URL Patterns**: Domain, subdomain, path structure
2. **Page Titles**: Keywords and semantic meaning
3. **Content Type**: Documents, videos, social media, etc.
4. **Context Clues**: Time opened, referrer information

### Common Grouping Patterns

#### By Domain/Service
- **Google Workspace**: Docs, Sheets, Drive files
- **Development**: GitHub, Stack Overflow, documentation
- **Social Media**: Twitter, LinkedIn, Facebook

#### By Content Type
- **Research**: Articles, papers, reference materials
- **Entertainment**: Videos, news, social content
- **Shopping**: E-commerce sites, product pages

#### By Project Context
- **Work Projects**: Related documents and resources
- **Learning**: Tutorials, courses, reference materials
- **Planning**: Travel, events, purchases

### Improving AI Accuracy

#### Provide Better Context
- **Use descriptive tab titles** when possible
- **Keep related tabs** open in same session
- **Organize similar content** in same windows

#### Regular Training
- **Rename workspaces** to provide feedback
- **Delete irrelevant groupings** to improve future results
- **Use consistent naming patterns** for similar projects

## 🚨 Troubleshooting

### Common Issues

#### No Workspaces Created
**Causes**: Too few tabs, similar content, permission issues
**Solutions**:
- Open more diverse tabs
- Check browser permissions
- Try analyzing different windows

#### Incorrect Groupings
**Causes**: Insufficient context, mixed content types
**Solutions**:
- Manually rename workspaces
- Remove outlier tabs before analysis
- Use specific window mode

#### Performance Issues
**Causes**: Too many tabs, low memory, browser conflicts
**Solutions**:
- Process smaller batches
- Close unnecessary tabs
- Restart browser

For more detailed troubleshooting, see the [Troubleshooting Guide](troubleshooting.md).

## 📊 Privacy and Data

### What Data is Processed
- **Tab URLs and titles** (processed locally)
- **Page content metadata** (not full content)
- **User preferences** (stored locally)

### What Data is NOT Collected
- **Browsing history** beyond current session
- **Personal information** from web pages
- **Passwords or sensitive data**
- **Data sent to external servers**

### Data Storage
- **Local storage only** - data stays on your device
- **No cloud sync** - your data remains private
- **Clear data option** available in settings
